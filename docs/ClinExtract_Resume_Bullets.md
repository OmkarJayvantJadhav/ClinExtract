# ClinExtract: Resume Bullets

## 1-Line Version (For Summary or Quick Bio)
*   Developed **ClinExtract**, an intelligent document processing platform that leverages NLP to automatically extract and structure medical entities from unstructured clinical notes.

## 3-Bullet Version (Standard Resume)
*   **ClinExtract (Full Stack Medical NLP Platform):** Architected and developed a full-stack application to automate the extraction of structured data (diagnoses, medications) from unstructured clinical text, significantly reducing manual data entry.
*   Designed a scalable, event-driven backend utilizing message queues to process NLP tasks asynchronously, ensuring high performance and a responsive user interface during heavy workloads.
*   Implemented a "human-in-the-loop" React interface featuring text-offset highlighting and confidence-score flagging, allowing clinicians to efficiently review and correct AI-extracted data.

## 4-Bullet Version (Detailed Tech Resume)
*   **ClinExtract (Intelligent Document Processing):** Built an end-to-end platform transforming raw clinical documents into structured, queryable data to improve healthcare administrative efficiency.
*   **Architecture & Backend:** Developed robust RESTful APIs and asynchronous worker pipelines to orchestrate specialized medical NLP models, handling complex tokenization and entity recognition.
*   **Frontend & UX:** Engineered a responsive React dashboard with a complex split-pane document viewer, mapping extracted JSON data back to precise text indices for seamless verification.
*   **Security & Reliability:** Implemented strict JWT authentication, role-based access control, and comprehensive audit logging to maintain data integrity and align with healthcare privacy standards.
